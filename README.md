# ajfuto.com
This is the source code for my personal website, [ajfuto.com](https://ajfuto.com).

## Technologies
- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [GitHub Pages](https://pages.github.com/)

## Development
```bash
git clone git@github.com:ajfuto/ajfuto.com.git
cd ajfuto.com
npm install
npm run dev
```

## Deployment
```bash
npm run build
npm run export
```
